# QuizJam デザインガイド

QuizJam の画面を実装するときの共通デザインルール。

## コンセプト

「楽しい・わかりやすい・盛り上がる」

クイズ中に迷わず操作できることを最優先にする。
GM画面は情報量を確保し、参加者画面はシンプルで大きな操作を中心にする。

## カラー

### メインカラー

青〜紫〜ピンク〜オレンジのグラデーションを QuizJam のアクセントとして使用する。

```css
background: linear-gradient(
  135deg,
  #2563eb,
  #7c3aed,
  #ec4899,
  #fb923c
);
```

### ベース

- GM画面: ダーク系
- 参加者画面: 白〜薄いグレー
- カード: 背景との差が分かる色
- 文字: 十分なコントラストを確保する

### 状態色

| 用途 | 色 |
|---|---|
| 正解 | Green |
| 不正解 | Red |
| 注意・残り時間 | Orange / Yellow |
| 通常アクション | Blue |
| QuizJam の主要アクション | ブランドグラデーション |

## 角丸

全体的に丸みのあるデザインにする。極端に角ばったUIは使用しない。

| 要素 | 角丸 |
|---|---|
| 小さいUI | 8px |
| 入力欄 | 12px |
| ボタン | 12〜16px |
| カード | 16px |
| 大きなカード | 20〜24px |

## ボタン

主要操作は大きく、分かりやすくする。主要ボタンにはブランドグラデーションを使用してよい。

主要操作の例:

- 参加する
- 開始する
- 回答する
- 次の問題へ

GM画面の「締切」「設定」「戻る」などの補助操作は、目立ちすぎない色にする。

## カード

情報はカード単位で整理する。カードには適度な余白を持たせ、情報を詰め込みすぎない。

カードの例:

- 問題
- ランキング
- 参加者
- タイマー
- 現在の得点
- 回答状況

## タイポグラフィ

日本語が読みやすいサンセリフ系を使用する。

```css
font-family:
  "Noto Sans JP",
  system-ui,
  sans-serif;
```

重要度によって文字サイズを大きく変える。特に「問題文 / 正解 / 不正解 / 順位」は一目で分かるサイズにする。

| 要素 | サイズ |
|---|---|
| 問題文 | 32〜64px |
| 結果表示 | 40〜72px |
| 画面タイトル | 24〜32px |
| 本文 | 14〜18px |
| 補足 | 12〜14px |

## アイコン

UI上のアイコンに絵文字は使用しない。OSSのアイコンライブラリを使用し、画面全体でデザインを統一する。

### 基本

第一候補として Lucide Icons（`lucide-react`）を使用する。

```tsx
import {
  Crown,
  Users,
  Timer,
  Settings,
  Check,
  X,
  Play,
  ArrowRight,
} from "lucide-react";
```

| アイコン | 用途 |
|---|---|
| Crown | ランキング・1位 |
| Users | 参加者 |
| Timer | 残り時間 |
| Zap | 早押し |
| Mic | 口頭回答・回答中 |
| Settings | 設定 |
| Check | 正解 |
| X | 不正解 |
| Play | ゲーム開始 |
| ArrowRight | 次へ |

### ルール

- 絵文字をUIアイコンとして使用しない
- 原則として Lucide に存在するアイコンを使う
- 同じ意味には同じアイコンを使う
- アイコンサイズを画面内で統一する
- 線の太さやスタイルが異なるアイコンセットを混在させない
- 重要な操作はアイコンだけにせず、テキストラベルも表示する
- 装飾目的でアイコンを大量に配置しない

### 基本サイズ

| 用途 | サイズ |
|---|---|
| 通常 | 20px |
| 小さいUI | 16px |
| 主要操作 | 20〜24px |
| 大きな演出 | 32px以上 |

Lucide に適切なアイコンが存在しない場合のみ、Heroicons など別のOSSライブラリを検討する。
ただし、1画面内で複数のアイコンセットを混在させない。

## GM画面

PC・プロジェクター表示を前提にする。

基本構成:

```text
┌───────────────────────────────┐
│ ヘッダー                       │
├───────────┬───────────────────┤
│           │                   │
│ メイン     │ ランキング         │
│           │                   │
├───────────┴───────────────────┤
│ 操作ボタン                     │
└───────────────────────────────┘
```

遠くから見ても次の要素が判別できるようにする。

- 問題
- 残り時間
- 正解者
- ランキング

### スライド

タイトル・説明スライドは 16:9 の枠に描き、GM 画面の本番表示と編集画面のプレビュー・サムネイルで同じ部品（`components/Slides.tsx`）を使う。文字サイズは枠の幅基準（`cqw`）で指定し、サムネイルでも大画面でも同じ比率で見える。

| スライド | 構成 |
|---|---|
| タイトル | 表紙画像を薄く敷き、企画名を中央に大きく。下に全n問・制限時間・お手付き上限 |
| 説明 | 画像があれば中央に大きく（枠の高さの 30% 以上を確保）、見出しを上、本文を下に添える。画像が無ければ見出しを大きく、本文をその下に |
| 問題 | 第n問と残り時間を上に、画像と出題文を中央に。問題セットの背景色があれば枠全体に敷き、明るい色なら文字を濃くする。早押しでは残り時間の代わりに「早押し」バッジ、問題文は左寄せ・改行を保ち、長さに応じて文字サイズを下げる（40 文字まで／100 文字まで／それ以上の 3 段階） |

- 説明スライドの本文は改行を保ち、長いほど文字を小さくして 1000 文字でも枠に収める。画像があるときは本文を枠の高さの 35% までに抑え、画像を主役にする
- サムネイル（compact）では本文・ヒント・制限時間などの細部を省く

## 参加者画面

スマートフォン縦画面を前提にする。1画面に必要な情報だけを表示する。

表示の優先順位:

1. 問題
2. 回答入力
3. 回答ボタン
4. 残り時間
5. 残り回答回数
6. 自分の順位・得点

主要操作は親指で押しやすいサイズにする。

| 要素 | 最小サイズ |
|---|---|
| ボタン高さ | 48px以上 |
| 入力欄高さ | 48px以上 |

### 早押しボタン

早押しモードではボタンが画面の主役になる。

- 幅 `min(80vw, 22rem)` の円形、ブランドグラデーション、Zap アイコンと「早押し！」
- 押せないときは薄く（opacity 30%）してシャドウを消す。押した後はボタンを消して状態の文言を出す
- 「あなたの番！」はブランド色で大きく、Mic アイコンを添える。`text-brand` は文字を透明にしてグラデーションを敷くユーティリティなので、`currentColor` で描く Lucide アイコンには付けない

## 正解演出

正解時はゲーム内で最も派手な演出にする。

表示例:

```text
[Crown icon]

正解！

1番目の正解です！

+150点
```

Crown や Check などのアイコンと、紙吹雪や軽いアニメーションを組み合わせてよい。
ただし演出は短時間で終了し、ゲーム進行を邪魔しない。

## 不正解

正解ほど派手にしない。

```text
[X icon]

不正解…

残り2回
```

赤を使用するが、画面全体を強烈な赤にしない。
再回答できる場合は、そのまま入力へ戻れるようにする。

## ランキング

上位3名は視覚的に区別する。メダルの絵文字は使わず、順位番号・色・Crown などのアイコンで表現する。

```text
1  みさき   350点
2  たろう   300点
3  ケン     250点
```

- 1位のみ Crown アイコンを付けるなど、過度にならない範囲で強調する。
- 自分の順位は上位でなくても分かりやすく強調する。
- 順位変更時に軽いアニメーションを使用してよい。

## アニメーション

使用する場所:

- 正解
- 得点追加
- ランキング変動
- 問題切り替え
- ポップアップ

基本は 150〜300ms 程度。操作を待たせる長いアニメーションは使用しない。

## 共通ルール

迷った場合は以下を優先する。

1. 一目で意味が分かる
2. 操作対象が大きい
3. 情報を詰め込みすぎない
4. クイズ中に考えなくても操作できる
5. 楽しい雰囲気を壊さない
6. アイコンや装飾のスタイルを統一する

QuizJam は業務システムのように堅くしすぎず、ゲームらしい楽しさと、迷わないUIを両立する。
