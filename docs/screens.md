# 画面構成

GM 画面・参加者画面・管理画面は1つの React SPA で、ルートで出し分ける。
配色・角丸・タイポグラフィ・アイコン・演出は [デザインガイド](design-guide.md) に従う。

## ルート

| パス | 画面 | 想定端末 |
|---|---|---|
| `/` | GM トップ | PC |
| `/gm/:code` | GM ルーム（待機・出題・結果・最終結果をフェーズで切替） | PC・プロジェクター |
| `/play/:code` | 参加者 入室 | スマートフォン |
| `/play/:code/game` | 参加者 ゲーム（待機・出題・結果・最終結果をフェーズで切替） | スマートフォン |
| `/admin` | 問題セット一覧 | PC |
| `/admin/:id` | 問題セット編集（`new` で新規） | PC |

## ブラウザ側の保存

localStorage に `quizjam:` プレフィックスで保存する。

| キー | 内容 |
|---|---|
| `gm:<code>` | GM トークン。ルーム作成時に保存し、`/gm/:code` を開き直したときの接続に使う |
| `player:<code>` | 参加者 ID・トークン・ニックネーム。入室時に保存し、`/play/:code` を開くと保存があればゲーム画面へ直行する。キック時に消す |
| `admin` | 管理画面の合言葉。開くたびにサーバーで検証し、無効なら消す |

## GM 画面（PC・横画面。プロジェクター投影を想定）

ダーク系。「ヘッダー／メイン＋ランキング／操作ボタン」の3段構成で、右カラムにはロビー中は参加者一覧、それ以外は順位表を常時表示する。
ヘッダーの「管理」ボタンはどのフェーズでも管理パネルを開く。

| フェーズ | 内容 |
|---|---|
| トップ | 「新しいルームを作る」ボタン。問題セット一覧と管理画面へのリンク |
| ロビー | 大きな QR コードと参加 URL・ルームコード。問題セット選択と「前のゲームのスコアを通算する」の切替。「開始する」（参加者が1名以上接続するまで無効）。「トップへ」 |
| タイトル・説明 | 企画名・表紙・全n問・制限時間・お手付き上限のタイトルスライド、続けて説明スライド（見出し・本文・画像）を 16:9 で表示。右カラムは参加者一覧。「次へ」（最後は「第1問へ」）「ロビーへ戻る」 |
| 出題中 | 第n問／全m問、残り時間、正解者数、問題画像（あれば）、問題文（大きく表示）、ヒント。正解者ポップアップと紙吹雪。「締切」「ロビーへ戻る」 |
| 問題結果 | 正解候補、この問題の正解者と正解順・得点。「次の問題へ」または「最終結果へ」。「ロビーへ戻る」 |
| 最終結果 | 1〜3位を強調した順位表。「もう1ゲーム」 |

- 問題セットに背景色があれば出題カードの背景に使い、明るい色なら文字を濃くする。
- 出題文が空の問題は画像だけを大きく表示する。
- 「ロビーへ戻る」は確認ダイアログを出す。
- タイトル・説明・問題のスライド描画は編集画面と `components/Slides.tsx` を共用する。

### 管理パネル

出題中でも開けるモーダル。Escape か背景クリックで閉じる。

- 設定の上書き: 制限時間モード・秒数・お手付き上限（「無制限」チェック）・基本点・不正解ペナルティ・正解順ボーナス。空欄はセットの設定。「適用」で今の問題にもすぐ反映。「上書きをすべて解除」でセットの設定に戻す
- 参加者一覧: 接続状態、点数、任意の刻み幅での＋／−、キック（確認ダイアログ付き）
- 途中参加用の QR コードと参加 URL

## 参加者画面（スマートフォン・縦画面）

白基調。主要操作（ボタン・入力欄）は高さ 48px 以上。接続が切れたら上部に「再接続中…」バナーを表示する。

| フェーズ | 内容 |
|---|---|
| 入室 | QR から開く。ニックネーム入力→「参加」。ルームが無ければ「ルームが見つかりません」。キック後に戻ってきた場合は「GMによってルームから退出されました」 |
| 待機 | 「まもなく開始します」、参加者数。タイトル・説明スライド表示中は企画名も表示する |
| 出題中 | 第n問、残り時間、問題画像、問題文、ヒント（既定では隠し、「ヒントを見る」で表示。問題が変わると隠し直す）、回答入力欄と送信ボタン、残り回答回数、自分の現在順位と点数 |
| 回答結果 | 「正解！ n番目の正解です！」または「不正解…」をその場に表示。不正解は入力欄を揺らす。正解後・上限到達後・締切後は入力を閉じる |
| 問題結果 | 正解、自分が正解したかどうか、自分の順位と点数、上位3名 |
| 最終結果 | 全体順位と自分の順位 |

順位表では自分の行をブランド色で強調する。

## 管理画面（PC）

合言葉でログインする。スライド形式のエディタで、3カラム構成。

| カラム | 内容 |
|---|---|
| 左 | スライド一覧。タイトル → 説明スライド → 各問題の順に 16:9 サムネイル。選択・↑↓キー／PageUp・PageDown で通しで移動 |
| 中央 | GM 画面と同じ見た目のプレビュー。右側の入力に追従する |
| 右 | 選択中スライドの内容。タイトルスライド: 企画名・表紙画像・問題スライドの背景色・全問共通の設定。説明スライド: 見出し・本文（複数行）・画像。問題スライド: 正解候補（複数）・出題文・画像・ヒント・問題ごとの上書き設定 |

- 問題の追加・複製・削除・並べ替え
- 説明スライドの追加・複製・削除・並べ替え（説明スライド同士の中で）。保存時に見出し・本文・画像がすべて空の説明スライドがあれば、そのスライドに移動して表示する
- 「生成」で正解候補からアナグラム文字列を作って出題文に入れる
- 画像はドロップまたは選択でアップロードし、ブラウザ側で縮小してから送る
- JSON のインポート／エクスポート。インポートはサーバーと同じバリデーションを通す
- 未保存のままページを離れようとすると警告する。保存時のバリデーションエラーは該当スライドに移動して表示する
- 一覧には表紙・企画名・問題数を表示し、削除は確認ダイアログ付き

## クライアント側の状態

サーバーからのメッセージは1つの reducer で `ClientState` に反映する。画面はこの状態とフェーズだけを見て描画し、メッセージを直接扱わない。

- `state` 受信で全体を置き換え、`serverTime` との差を時計補正値として持つ
- `introStarted` で `intro` を置き、問題と結果を消す。タイトルスライドから企画名も取り込む。`questionStarted` で `intro` を消す
- `questionStarted` で自分の回答状況・前回の判定結果・正解者数をリセットする
- `someoneCorrect` はポップアップのキューに積む（最大5件）。GM 画面はポップアップごとに紙吹雪を出す
- `leaderboard` は順位表と参加者一覧の点数、自分の点数を同時に更新する
- `kicked` で参加者はトークンを消して入室画面に戻る
